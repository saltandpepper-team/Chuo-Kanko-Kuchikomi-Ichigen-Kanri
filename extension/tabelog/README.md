# 口コミ返信アシスタント（食べログ・トリップアドバイザー／Chrome拡張機能）

食べログ店舗管理画面とトリップアドバイザー（Tripadvisor for Business）の新着口コミを確認して口コミ一元管理アプリに表示し、アプリのAIが作った返信文を返信欄に入力します。担当者は内容を確認して「返信」「送信」ボタンを押すだけです。

- 一定間隔（初期値30分）で「口コミ返信」ページを裏で開いて新着を確認します。ログインが切れていれば自動でログインします。
- 未返信の新着があれば、PCに通知を出します（クリックするとアプリが開きます）。
- **返信文はアプリの中でAI（Gemini／Firebase AI Logic）が作成します。** 拡張機能にAPIキーを入れる必要はありません（OpenAIは使いません）。
- 「口コミ返信」ページを開くと、未返信の口コミの返信欄にAIの返信文が入っています。「返信する」を押してから返信欄が出る画面にも対応しています。
- **返信（送信）ボタンは拡張機能では押しません。** 担当者が入力した文面は上書きしません。
- 書き直すときは、アプリの「指示を入れて書き直す」を使ってください。

## トリップアドバイザー

- 設定画面の「場所ID」（口コミ画面のURL `…/reviews?locationId=この数字` ）の店舗を、食べログと同じ間隔で確認します。山麓園は `1703726` が初期値です。
- 口コミ画面（`tripadvisor.jp/reviews?locationId=…`）を開くと、未返信の口コミが自動で開き、「Your response」欄にAIの返信文が入ります。内容を確認して「送信」を押してください。
- **自動ログインはしません。** このChromeで一度「ログイン状態を保持」にしてログインしておいてください。ログインが切れているときは通知が出ます。
- 返信済みかどうかは「公開された返信」「返信を削除する」の表示から判断しています。

## 口コミ一元管理アプリとの連携

拡張機能が読み取った口コミは、同じPCのChromeで開いたアプリ（口コミ一元管理_返信文自動生成）にも自動で表示されます。

- アプリのAIが返信文を作ると、その文が拡張機能に届き、各媒体の返信欄に入ります（アプリを一度開いておく必要があります）。
- アプリの「承認して自動入力」で管理画面を開くと、**その口コミの場所まで自動で移動**し、返信欄を開いて返信文を入れます（食べログで別のページにある口コミは、ページを移るよう案内が出ます）。
- アプリで返信文を直して「承認して自動入力」を押すと、その文が食べログの返信欄に入ります。
- 食べログで返信すると、次の確認のときにアプリでも「返信済み」になります。
- 対象のアプリ：本番URL（`chuo-kanko-kuchikomi-ichigen-kanri.firebaseapp.com`／`.web.app`）、claude.ai の公開版、PCに保存したHTMLファイル。
- PCに保存したHTMLファイルで使う場合は、`chrome://extensions` → この拡張機能の「詳細」→ **「ファイルの URL へのアクセスを許可する」** をオンにしてください。

## インストール（担当者のPCで1回だけ）

1. このフォルダ（`extension/tabelog`）をPCに保存します。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選びます。
4. 拡張機能の「詳細」→「拡張機能のオプション」を開き、次を入力して「保存する」を押します。
   - 食べログ店舗管理画面のログインID・パスワード（自動ログイン用）
5. 「今すぐ確認する」を押し、「状態」に「口コミ ○件を確認」と出れば完了です。

入力した内容は、そのPCのChromeの中（`chrome.storage.local`）にだけ保存されます。

## 注意

- **確認はPCとChromeが起動しているときだけ行われます。**
- 画像認証などで自動ログインできない場合は、通知が出ます。食べログに手動でログインしてください。
- 口コミの見つけ方は、ページ上の「日付（'26/07/26 （'26/07 訪問））」「投稿者名（件数）」の並びと返信欄の位置から判断しています。食べログの画面が変わって読み取れなくなった場合は、`parser.js`（アプリ本体 `public/index.html` と同じロジック）を調整してください。
- 返信済みかどうかは「店舗からの返信」などの表示から判断しています。実際の表示文言が異なる場合は `parser.js` の `TB_REPLIED` を調整してください。
- 食べログの利用規約では自動化された方法でのアクセスが制限されている場合があります。確認の間隔は長め（30分以上）での運用をおすすめします。
